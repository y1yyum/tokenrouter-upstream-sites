# 上游站点插件

上游站点管理插件 `local.upstream-sites`，源码版本 1.2.0。

第三方独立插件，使用官方插件接口提供管理页面，无需替换 TokenRouter 主程序。自动停用与自动恢复默认关闭。

下载：[最新版本与安装包](https://github.com/y1yyum/tokenrouter-upstream-sites/releases/latest) · [更新记录](CHANGELOG.md) · [来源与许可](THIRD_PARTY_NOTICES.md)

发布的安装包适用于 **Linux amd64**。其他平台需要自行编译，当前未提供兼容性验证。

## 使用

在后台“插件管理”上传安装包，配置并启用后，从“上游站点”菜单进入。

从 Releases 下载所需版本的安装包，可使用同页的校验清单核对。插件配置中的管理 API 密钥填写自己的 TokenRouter 管理密钥，数据加密密钥需固定保存。仅监控余额时可留空“原子控制连接”，需要自动启停时按后文安装控制桥。

- 管理站点、多协议 BaseURL、余额查询凭据、查询间隔、定时探针和告警阈值。
- 在“提供商绑定”中选择站点，也可扫描现有 BaseURL，核对建议后批量保存。绑定不会修改提供商地址、Key、手动状态或调度开关。
- 余额只接受账户余额，不把单个 Key 的额度当作站点余额。填写能查询账户余额的 Key；New API 可额外填写账户访问令牌与用户 ID。
- 查看查询与探针历史、每日消耗及告警。余额下降属于估算；账户累计消费差额单独展示。币种、钱包变更和时区变更分段统计。
- 自动控制默认关闭，可按余额、必需探针或两者共同控制。支持停用/恢复余额阈值、连续次数、最短停用时间；自动恢复是独立开关，默认关闭。
- 同一站点全部绑定提供商一起受控。多个原因分别解除，最后一个原因解除前不会恢复；每日消耗仍只统计和告警。
- 401/403、429、缺少账户余额、无效响应、TLS 配置错误和监控代理失败不会被当作零余额。连接失败和上游 5xx 可触发不可访问停用；探针明确返回不符合预期的 JSON 值可触发探针异常停用。

插件设置中的管理 API 地址必须为本机回环地址，默认 `http://127.0.0.1:8080`。管理 API 密钥供后台读取提供商列表，浏览器不会获得它。数据加密密钥为 64 位十六进制字符串，必须固定保存；已有数据时不可直接更换，否则无法解密站点凭据。

## 余额倍率和人民币成本

在「新增上游站点」或「编辑上游站点」填写选填的余额倍率。**倍率 = 充值实际到账额度 ÷ 实付人民币元**。充值 100 元到账 200 额度就填 `2`，到账 50 额度就填 `0.5`。多单位钱包分别填写。CNY 留空按 1 估算。USD、TOKENS 留空时仍显示站内余额，人民币金额显示待设倍率。

余额总览按原单位汇总最近的有效余额，同时给出已折合的人民币小计。每个上游钱包建一个站点，可绑定多个提供商。报表标出过期、归档、未采样与缺倍率的站点。当前余额按当前倍率折合，历史成本使用采样时记录的倍率。

例如余额依次为 100、80、130、120，观察到的上涨是 50，两次下降合计 30。倍率为 2 时成本为 15 元，最后的 120 额度折合 60 元。两次采样之间同时充值和消费会抵消，只能估算。记录页另列上游可提供的账户累计消费差额、缺测补记、未计价下降额和实测余额范围。跨倍率的区间保留原单位下降额。

管理员可通过 `GET /api/v1/plugins/local.upstream-sites/api/statistics/overview` 读取总览。`period` 接受 `today`（默认）、`7d`、`30d` 或 `retained`。例如 `?period=7d&timezone=Asia%2FShanghai` 读取上海时区站点近 7 个日历日的成本。当前余额仍覆盖所有符合条件的站点。单站每日记录从同一前缀下的 `GET /sites/{id}/daily` 读取。

## New API 账户余额

查询顺序为 `/api/status`、`/api/usage/token/` 的账户字段、可选的 `/api/user/self`、最后 `/user/balance`。`total_granted`、`total_used`、`total_available`、单 Key 的 `quota` 和无限额度标志均不作为账户余额，也不校验 Key 限额是否一致。仅有账户访问令牌时可直接查询用户接口。

- 内嵌账户余额优先使用 `user_balance_display`，其次 `user_balance`；前者为显示金额，后者为原始账户额度。优先字段存在但无效时停止，不改用其他余额。
- 使用站点显示设置转换 USD、CNY、TOKENS；设置缺失时沿用官方默认 USD、每单位 500000、汇率 1。可选设置请求限时 3 秒，整轮请求限时 25 秒。金额用十进制计算，最多 10 位小数，保留合法的欠费负余额。
- 用户接口只读取账户 `quota`，不把累计 `used_quota` 拼成钱包总额。配置用户 ID 时必须返回相同的正整数 ID；使用精确整数校验，避免大整数被浮点舍入。
- 兼容接口接受原实现的根对象、`data` 对象和 `balance_infos`；优先选择站点币种，支持 `total_balance`、`balance`、`remaining` 及账户对象的 `quota`。
- 认证拒绝、身份不符、限流、超时会停止查询；用户接口的非认证错误可尝试兼容接口。HTML、缺少账户字段或无效金额不产生余额。请求不跟随重定向，账户令牌和用户 ID 只发送至用户接口。

若现有 API Key 只返回 Key 额度，请在站点编辑页补充具有账户余额读取权限的“账户访问令牌”，并按上游要求填写“账户用户 ID”。普通模型调用 Key 无法保证能读取账户余额。

## 人工停用保护与控制安装

官方 0.7.1 的管理 API 没有原子条件恢复接口。仅在 HTTP 写入前检查一次状态，无法避免与人工操作同时发生时的误恢复。因此本版使用 `control_bridge.sql` 在独立 `upstream_site_control` schema 中保存停用归属，并在提供商 `schedulable` 字段上安装触发器；主程序仍使用未经修改的官方镜像。

- 初次停用时保存原有开关；原本关闭的提供商恢复后仍关闭。
- 停用期间人工再次关闭，即使是 `false → false`，也会保存这次选择。恢复与人工关闭并发时，由同一提供商行锁串行处理。
- 人工或其他宿主功能修改开关均按外部选择保留。人工开启会被记住，但站点限制解除前仍不参与调度。
- 恢复只解除插件拥有的停用，不改提供商 `status`、有效期、限额、错误状态或其他健康限制。
- 开关变更和官方调度 outbox 在同一事务提交，随后由官方服务更新缓存。已经在途的请求不会被取消。

安装控制桥时，用数据库管理账号执行 `control_bridge.sql`，再创建专用登录角色，仅授予目标数据库 CONNECT、`upstream_site_control` schema 的 USAGE，以及 `reconcile()`、`snapshot()` 两个函数的 EXECUTE。不要授予提供商、设置或插件 KV 表的读写权限。将该角色的 PostgreSQL DSN 填入插件“原子控制连接”，保存并重启插件。

缺少控制连接时仍可安装并使用监控，但不能开启自动控制。已配置连接失效时控制失败保留已有停用，修复连接后重试。停用记录持久化，不随插件崩溃、重启或禁用自动解除。

关闭某站点控制会解除该站点的插件停用，保留人工选择。卸载或长期禁用插件前，应先在连接正常时关闭全部站点控制，确认“插件停用”为 0。不要直接删除停用记录，否则会丢失原有人工选择。

告警记录默认保存在插件内。插件设置的“告警接收用户 ID”为 0 时不发送邮件；填写有效用户 ID 后使用宿主通知服务，仍受邮箱、订阅偏好、SMTP 和插件邮件额度限制。邮件发送结果不明时不盲目重发。

## 更新与备份

更新主程序时保留 PostgreSQL 数据库、应用数据目录中的 `plugins` 安装目录，以及宿主的固定加密密钥。插件记录使用官方 `plugin_kv` 存储，插件配置及加密密钥由宿主加密保存。

本插件不依赖旧原生 `upstream_sites` 表、提供商扩展字段或定制路由。自动控制依赖上述数据库保护和官方调度 outbox；未来宿主存在不兼容的插件协议、数据库或管理 API 变更时，需要先验证兼容性。上传安装包应自行留存；上传来源丢失文件时无法从插件市场重新下载。

完整备份应包含 PostgreSQL 全库、数据库角色、应用数据目录及固定加密密钥。只导出插件 KV 不足以恢复控制桥触发器、函数、专用角色和正在生效的人工保护记录。

站点原始记录默认保留 90 天，每日汇总和事件默认保留 365 天。新版按统计日计算余额汇总的到期日。升级时保留旧版原单位数据，缺少历史价格快照的区间显示未计价。回退前备份插件 KV 和站点配置。如果回退期间用 1.1.1 查询或编辑过站点，再次升级后核对该站点倍率。宿主 KV 有总容量限制，高频探针和大量站点部署可在宿主查看用量。

## 构建与验证

源代码附带 `vendor`，可在没有 TokenRouter 源码的独立目录构建。需要 Go 1.27.3 或兼容的新版本；前端直接使用宿主提供的 Vue 与 SDK，无额外前端构建步骤。

```sh
go test -mod=vendor ./...
go vet -mod=vendor ./...
node --test tests/frontend.test.cjs
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -mod=vendor -buildvcs=false -trimpath -ldflags='-s -w' -o backend/plugin .
tar -czf upstream-sites-plugin.tar.gz plugin.json backend/plugin frontend LICENSE COPYING THIRD_PARTY_NOTICES.md control_bridge.sql
```

Windows PowerShell 需要用 `$env:GOOS='linux'` 等环境变量语法。打包后应在官方宿主上预览、安装并验证。

部分账户余额解析、金额模型、统计和加密代码沿用此前 TokenRouter 定制实现，保留 LGPL-3.0-or-later 许可证。官方插件 SDK 及其依赖的许可证保留在 `vendor` 中。
